# 7.7 稠密连接网络（DenseNet）

一定程度上是 ResNet 的逻辑扩展。

## 数学逻辑

ResNet 将函数展开为：

$$
f(x) = x + g(x)
$$

更进一步，将 $g(X)$ 拓展为超过两部分的信息，而不是简单相加。

ResNet 和 DenseNet 的关键区别在于，DenseNet 输出是连接而不是相加。

展开式结合到多层感知机中，将它们连接起来。
最后一层与之前的每一层连接。

助手补充：这里的“连接”是沿通道维拼接。在同一个稠密块里，每个卷积块都会接收原始输入和前面各卷积块产生的特征。

```text
原始输入 X
第 1 个卷积块：使用 X，产生 Y1
第 2 个卷积块：使用 [X, Y1]，产生 Y2
第 3 个卷积块：使用 [X, Y1, Y2]，产生 Y3
最终输出：[X, Y1, Y2, Y3]
```

## 稠密块体与过渡层

助手补充：本节的代码摘录、公式说明和形状推算是在原有简记上补充的，示例形状未在本次运行验证。

### 稠密块体

代码实现的关键在 `DenseBlock.forward`：

```python
def forward(self, X):
    for blk in self.net:
        Y = blk(X)                       # 产生新特征
        X = torch.cat((X, Y), dim=1)      # 保留已有特征，拼接新特征
    return X
```

张量形状是 `(批量大小, 通道数, 高, 宽)`，所以 `dim=1` 是通道维。拼接时，其他维度需要相同。

由于是循环连接，通道数量会不断增长。每个卷积块新增固定数量的通道，因此块内通道数随卷积块数量线性增长。

$$
C_{\text{输出}} = C_{\text{输入}} + n k
$$

- $C_{\text{输入}}$：进入整个稠密块时的通道数。
- $n$：稠密块内部的卷积块数量。
- $k$：每个卷积块新增的通道数，也叫增长率。

在当前代码中，`out_channels` 表示增长率 $k$。第 `i` 个卷积块的输入通道数是 `in_channels + i * out_channels`，其中 `i` 从 0 开始。

例如，`DenseBlock(2, 3, 10)` 的输入有 3 个通道，内部有 2 个卷积块，每个新增 10 个通道：

```text
输入：              (4, 3, 8, 8)
第 1 次卷积产生：    (4, 10, 8, 8)
拼接后：            (4, 13, 8, 8)
第 2 次卷积产生：    (4, 10, 8, 8)
再次拼接后：        (4, 23, 8, 8)
```

最终通道数为 $3 + 2 \times 10 = 23$。这里的卷积使用 `kernel_size=3, padding=1`，默认步幅为 1，因此高、宽保持不变。

### 过渡层

通过过渡层，控制模型复杂度。

教材中的过渡层按下面的顺序实现：

```python
def transition_block(in_channels, out_channels):
    return nn.Sequential(
        nn.BatchNorm2d(in_channels), nn.ReLU(),
        nn.Conv2d(in_channels, out_channels, kernel_size=1),
        nn.AvgPool2d(kernel_size=2, stride=2)
    )
```

- `1×1` 卷积：通过设置较小的输出通道数来压缩通道，高、宽不变。
- 平均汇聚：高、宽减半，通道数不变。

接着上面的例子，使用 `transition_block(23, 10)`：

```text
(4, 23, 8, 8)
  → 1×1 卷积 → (4, 10, 8, 8)
  → 平均汇聚 → (4, 10, 4, 4)
```

## DenseNet 模型

助手补充：完整模型由这些模块组合而成，结构可以先这样看：

```text
输入
→ 初始卷积、BN、ReLU、最大汇聚
→ 稠密块 → 过渡层
→ 稠密块 → 过渡层
→ 稠密块 → 过渡层
→ 最后一个稠密块
→ BN、ReLU
→ 全局平均汇聚
→ 展平、全连接分类
```

稠密块负责保留并增加特征，过渡层负责压缩通道和空间尺寸。

教材中，每个稠密块有 4 个卷积块，增长率为 32，所以每个稠密块增加 $4 \times 32 = 128$ 个通道。前三个稠密块后面接过渡层，最后一个后面接分类部分。

教材卷积块的顺序是 `BN → ReLU → 卷积`；当前 `7.7.py` 中写的是 `卷积 → BN → ReLU`，顺序差异待对照。
