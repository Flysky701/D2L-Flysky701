## 使用说明

代码主要使用 Python、PyTorch、torchvision 和 d2l；不同示例可能需要其他依赖或数据。数据集、模型权重、运行结果与教材 PDF 不包含在仓库中。运行训练脚本前请查看脚本说明，并自行准备所需数据。

可参考原学习环境：Python 3.9、PyTorch 2.0.1、torchvision 0.15.2 和 d2l 1.0.3。安装命令与 CUDA 版本需按自己的系统选择；例如使用虚拟环境后，可运行 `pip install torch==2.0.1 torchvision==0.15.2 d2l==1.0.3`。各章节笔记中的运行命令以 `DIDL` 目录为工作目录。
