# 8.5 循环神经网络的从零开始实现

实现，大部分代码在 [8.5.py](8.5.py)。
下面只会简单讲述。

正常引入数据源，复用 8.3 的数据加载器。

下面的“代码思路”为整理补充，作为回看代码的导航。

形状记号：$B$ 为批量大小，$T$ 为时间步数，$V$ 为词表大小，$h$ 为隐藏单元数。

## 8.5.1 独热编码

将 token 表现为特征向量，方便模型使用。
曾经在 3.4.1 讲解过，大致就是一个位置为 1，其他都是 0。

代码思路：对应 `RNNModelScratch.__call__()` 中的输入转换。

- 编号批次原本是 `(B, T)`，先转置，再把每个编号变成长度为 $V$ 的独热向量。
- 转换后是 `(T, B, V)`，方便沿最外层逐个时间步读取，每次得到 `X_t`，形状为 `(B, V)`。
- 转换成与模型参数相同的浮点类型和设备，供矩阵乘法使用。

```text
编号批次 (B, T) → 转置 (T, B) → 独热编码 (T, B, V)
```

## 8.5.2 初始化模型参数

正常初始化即可。

代码思路：对应 `get_params()`。

- 使用独热编码，输入维度是 $V$；预测词表中的下一个词元，输出维度也是 $V$。
- `num_hiddens` 决定隐藏单元数 $h$。
- 准备三组权重：`W_xh` 为 `(V, h)`，`W_hh` 为 `(h, h)`，`W_hq` 为 `(h, V)`。
- 准备两组偏置：`b_h` 为 `(h,)`，`b_q` 为 `(V,)`。
- 权重用小随机数初始化，偏置为 0；`requires_grad_(True)` 让自动微分记录这些参数的梯度。

## 8.5.3 循环神经网络模型

代码思路：初始化状态 → 按时间步计算 → 汇总输出。

`init_rnn_state()`：每条序列准备一个全零状态，形状为 `(B, h)`，用 `(H,)` 元组返回。

`rnn()`：遍历独热编码后的输入，每次取出一个时间步。

```python
H = torch.tanh(X @ W_xh + H @ W_hh + b_h)
Y = H @ W_hq + b_q
```

- 第一行：当前输入和旧状态共同计算新状态。
- 第二行：新状态映射为词表中每个候选词元的分数，形状为 `(B, V)`。这里的 `Y` 是输出分数，训练标签由数据加载器另外提供。
- 每一步使用相同的权重和偏置，变化的是输入与隐状态。
- 将各时间步的输出沿第 0 维拼接，得到 `(T * B, V)`；同时返回最后的状态 `(H,)`。

`RNNModelScratch` 把上面的函数包装起来：创建模型时准备参数，`begin_state()` 创建初始状态，`__call__()` 转换输入并调用 `rnn()`。

```text
net(X, state)
→ __call__() 转置、独热编码
→ rnn() 逐时间步计算
→ 所有位置的输出分数、最后的隐状态
```

## 8.5.4 预测

代码思路：对应 `predict_ch8(prefix, num_preds, net, vocab, device)`，在给定前缀后续写 `num_preds` 个字符。

- 先初始化批量大小为 1 的隐状态，并保存前缀的第一个字符编号。
- `get_input()` 每次取目前最后一个字符编号，整理成 `(1, 1)` 的输入。
- 预热：依次读入前缀中末尾字符之前的内容，更新状态，丢弃输出分数，接着放入已知的下一个前缀字符。
- 生成：先读入前缀的最后一个字符，再用 `argmax` 选择输出分数最高的新字符；把它接到结果中，作为下一步的输入。
- 最后把编号还原成文本，返回“原前缀 + 新生成的字符”。预热和生成过程中都不更新模型权重。

例如前缀是 `abc`，假设后续选中的字符为 `d`、`e`：

```text
预热：读 a → 接上已知的 b；读 b → 接上已知的 c
生成：读 c → 选出 d；读 d → 选出 e
返回：abcde
```

当前 `main()` 演示的是小输入的前向计算，`predict_ch8()` 已定义，尚未在演示中调用；生成质量需要在模型训练后再看。


## 8.5.5 梯度裁剪

如前面提到过的4.8的内容，由于要计算T个时间上的梯度，很容易出现梯度爆炸的情况
所以需要额外的方式来支持训练。

所以有一个裁剪值， 当范数没有超过阈值， 就保持原样

公式补充：将所有参数的梯度展开并拼接为向量 $g$，裁剪阈值为 $\theta>0$。总范数为：

$$
\|g\|_2=\sqrt{\sum_i g_i^2}
$$

如果超过了：就根据整个梯度的总长度，统一缩放

$$
g\leftarrow\min\left(1,\frac{\theta}{\|g\|_2}\right)g
$$

未超过阈值时系数为 1；超过时按 $\theta/\|g\|_2$ 缩小，保持梯度方向。

总的来说， 就是限制更新幅度， 按比例缩小

以学习率为 $\eta$ 的普通梯度下降为例，使用裁剪后的梯度更新参数 $w$：

$$
w\leftarrow w-\eta g,\qquad
\|\Delta w\|_2=\eta\|g\|_2\leq\eta\theta
$$

清零梯度 → 反向传播得到梯度 → 梯度裁剪 → 更新参数


## 8.5.6 训练

和之前的训练略有区别：

- 序列数据的采样方式不同，隐状态的初始化方式也不同。
- 在更新模型参数前裁剪梯度，避免梯度爆炸。
- 使用困惑度来评价模型。

隐状态的初始化：

- 顺序分区：在每个迭代周期的开始位置初始化隐状态。
